# Missões

## As Ruínas Despertaram

**Tipo:** principal

Objetivos:

- [ ] Falar com Elias
- [ ] Encontrar o Altar Antigo
- [ ] Encontrar as Ruínas Antigas
- [ ] Retornar para Elias

**Recompensa:** +50 XP

## Pegadas no Lago

**Tipo:** secundária

Objetivos:

- [ ] Falar com Tom
- [ ] Ir até o lago
- [ ] Encontrar as pegadas
- [ ] Observar a criatura
- [ ] Retornar para Tom

**Recompensa:** +25 XP

## Princípios

As missões devem incentivar exploração, observação e interação. O jogo não deve transformar cada objetivo em um marcador de GPS; parte da descoberta deve permanecer nas mãos do jogador.
