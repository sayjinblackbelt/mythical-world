# Gameplay

## Controles

| Ação | Desktop | Mobile |
|---|---|---|
| Movimento | WASD / Setas | Direcional virtual |
| Interagir | J / Enter | Botão de interação |
| Menu | ESC | Botão de menu |

## Exploração

O mapa é contínuo e maior que a área visível da tela. O jogador percorre floresta, áreas abertas, lago, vila e ruínas.

Pontos de interesse incentivam a exploração:

- Semente Mística
- Altar Antigo
- Lago Esquecido
- Ponte das Raízes
- Ruínas Antigas

## Criaturas

A Lumíria acompanha o jogador depois de criar vínculo com ela. Criaturas selvagens possuem habitats próprios e podem iniciar encontros.

## Combate

O combate atual é propositalmente simples e em tempo real. A criatura ativa possui HP e um ataque básico. O jogador pode atacar ou fugir. Vitória concede XP; derrota não causa morte permanente.

## Vínculo

Após um encontro, o jogador pode tentar criar vínculo com a criatura. O objetivo é diferenciar o sistema de coleção por meio de confiança e exploração.

## Missões

As missões possuem título, descrição, objetivos, progresso, status e recompensa. A primeira missão principal é **As Ruínas Despertaram**. A primeira missão secundária é **Pegadas no Lago**.

## Salvamento

O protótipo utiliza armazenamento local do navegador para preservar o progresso do jogador. Não há login nem servidor necessário para o protótipo.
