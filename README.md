# 🐉 Mythical World

> **Explore. Descubra. Crie vínculos. Evolua.**

Mythical World é um RPG 2D de exploração em pixel art, inspirado na sensação de aventura dos RPGs clássicos e em jogos de criaturas, mas desenvolvido com identidade própria.

O jogador explora um pequeno mundo aberto, encontra criaturas mitológicas, cria vínculos, realiza missões, coleta recursos e desenvolve sua jornada.

## 🎮 Projeto

**Status:** protótipo avançado em desenvolvimento  
**Versão de planejamento:** V0.7.2  
**Base funcional atual:** V0.7.1  
**Tecnologia de prototipagem:** Base44  
**Código/documentação:** GitHub

O protótipo funcional continua no Base44. O repositório mantém a documentação, o planejamento, o histórico e a estrutura de publicação do projeto. O código/build jogável ainda não foi exportado do Base44 para este repositório.

## ✨ Pilares

- 🗺️ **Exploração** — descobrir é parte central da experiência.
- 🐾 **Criaturas** — encontros, vínculo e progressão.
- 📜 **Missões** — pequenas histórias que dão propósito à exploração.
- ⚔️ **Combate** — simples e em tempo real.
- 🌱 **Progressão** — descobertas, missões, encontros e recursos geram desenvolvimento.
- 👤 **Identidade** — o jogador possui nome, categoria e perfil próprios.
- 🌎 **Mundo vivo** — NPCs, regiões, descobertas e interações ampliam a sensação de mundo.
