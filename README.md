# 🐉 Mythical World

> **Explore. Descubra. Crie vínculos. Evolua.**

Mythical World é um RPG 2D de exploração em pixel art, inspirado na sensação de aventura dos RPGs clássicos e em jogos de coleção de criaturas, mas desenvolvido com identidade própria.

O jogador explora um pequeno mundo aberto, encontra criaturas mitológicas, cria vínculos, realiza missões e evolui sua equipe.
